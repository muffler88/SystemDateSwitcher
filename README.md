# System Date Switcher 2.0

Приложение меняет системную дату по дням и автоматически останавливается на заданной конечной дате.

## Важно
Обычное Android-приложение не может произвольно менять системные часы только потому, что в APK указано `SET_TIME`. В этой версии используется официальный `DevicePolicyManager.setTime()`; для этого приложение должно быть назначено **Device Owner**.

### Сборка на GitHub
Откройте **Actions → Build APK → Run workflow**. После успешной сборки APK находится в **Artifacts → SystemDateSwitcher-debug**.

### Первичная настройка телефона
1. Установите APK.
2. Включите USB debugging.
3. Подключите телефон к ПК с ADB.
4. Выполните:
   `adb shell dpm set-device-owner com.example.dateswitcher/.DateAdminReceiver`
5. Откройте приложение и убедитесь, что показано `Device Owner: ДА`.
6. Укажите начальную дату, дату остановки и интервал.
7. Нажмите `СТАРТ`.

Команда Device Owner обычно требует устройство/пользователя без уже настроенного управления устройством; если Android отклоняет команду, не удаляйте системные данные вслепую — сначала проверьте сообщение ADB.
